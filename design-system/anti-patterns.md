# Midimily 反模式与停止条件

## 1. 视觉反模式

- 三列等宽卡片、统一卡片承载所有内容、每个区块都是标题 + 描述 + 卡片 + 按钮。
- 渐变光斑、玻璃拟态、Liquid Glass、网格背景、漂浮几何体、发光节点、无意义连接线。
- 大面积蓝紫、AI 大脑、机器人、芯片、电路线、宇宙、数据流、全息界面和通用未来城市。
- 空洞的全屏大字或大留白；留白必须分隔阅读阶段或强化唯一主角。
- 为“编辑感”滥用横线、括号、等宽字体、Issue 编号和索引编号。
- 所有图片圆角、所有容器圆角、阴影卡片和 Hover 上浮。

## 2. 内容包装反模式

- `Featured`、`Latest`、`Insight` 等装饰性英文微标签。
- 假作者、假日期、假阅读量、假客户、假数据、假排名、假热门和假案例。
- 把普通文章列表包装成“知识系统”、轨道、节点或仪表盘。
- 用 AI、Agent、Workflow 等技术词作装饰，而不说明真实任务与人的变化。
- 为了填满版面增加摘要、标签、按钮或图标；信息字段必须由内容角色决定。

## 3. 交互反模式

- 卡片上浮、鼠标跟随、滚动淡入、无意义视差、装饰性粒子或轨道动画。
- 发光按钮、箭头平移动画、自动轮播、新闻跑马灯。
- 只在 Hover 才暴露必要信息；移除 Focus 或造成键盘顺序与视觉顺序不一致。
- 用动效弥补静态层级不成立。

## 4. 禁止直接模仿

Linear / Vercel 的开发者 SaaS 语法、Notion 的数据库知识页、Arc 的渐变品牌、Stripe 的抽象科技插图、Apple 的产品大图、Bloomberg 的高密度、The Verge 的强视觉媒体、Substack 的作者 Newsletter、通用 AI 创业公司 Landing Page，都不能成为页面骨架。最多借鉴单一可验证能力，例如 Vercel 的文档可读性或 Apple 的图像裁切纪律；不得同时借入其配色、排版、组件和交互标志。

## 5. 硬性停止规则

若同一设计同时出现三个或以上典型 AI UI 特征，立即停止实现并重新设计。检查时将“大无衬线字”“黑白亮蓝”“细边框”“空留白”“英文眉题”“虚构编号”“几何背景”“卡片阵列”“滚动动画”等分别计为一项。

允许最多两个低风险特征的条件：每项都承担可指出的内容职责，移除后会损害理解，而不是只损害气氛。

## 6. 提交前自检

| 判断项 | 通过标准 | 失败表现 |
|---|---|---|
| 品牌识别 | 无 Logo 仍可见稳定左轴、非对称权重和编辑批注 | 可替换成任意 AI 媒体名称 |
| 编辑判断 | 有一个明确主角和一条真实判断 | 所有内容同权、只有栏目包装 |
| 人本表达 | 内容回到人的任务、情境或结果 | 模型、功能或抽象图形成为主体 |
| 图像信息价值 | 每张图提供人物、界面、现场或结果证据 | 图片只填位置 |
| 卡片依赖 | 内容分组主要靠排版、宽度、留白和规则线 | 删除卡片后结构崩溃 |
| 英文装饰 | 英文只用于真实术语或名称 | 微标签可删而信息不变 |
| 几何装饰 | 图形对应真实结构或数据 | 线、点、球体只有气氛作用 |
| 移动端节奏 | 单列重排仍保持主次和触控尺寸 | 只是桌面缩小或三张等卡片 |
| 内容可读性 | 长标题、摘要和辅助文字均可自然阅读 | 标题挤压、辅助字过淡或横滚 |
| AI UI 风险 | 命中不超过两项低风险特征 | 同时命中三项及以上 |
