# Pattern：Editorial Note / 编辑批注

## 目的

编辑批注表达 Midimily 对内容的判断：它说明“为什么值得看”或“真正重要的是什么”，不复述标题，不模拟系统通知。

## 内容规则

- 只使用真实、可由正文支持的判断，最多两句。
- 不包含作者、日期、排名、Issue 或营销 CTA。
- 同一首屏最多一个；同一文章详情页头部最多一个。
- 没有独立判断时省略，不用摘要代填。

## 结构与语义

- 独立于标题与摘要，使用 `aside`；有可见或无障碍名称“编辑批注”。
- 不作为链接或可展开控件。
- DOM 顺序应位于其所评论内容之后；桌面可用 CSS 布局放到侧轴。

## 视觉规则

- 文字使用 `--mily-editorial-note`，线条使用 `--mily-editorial-accent`。
- 字号桌面 16–17px，移动 15–16px；行高约 1.68–1.76。
- 左侧短线用于流内批注，顶部短线用于宽桌面页边注；线宽 2px，文章头部顶部强调可用 3px。
- 无圆角、背景、阴影、引号造型、气泡或图标。
- 批注的视觉权重必须低于标题与摘要。

## 响应式

- 桌面：可位于 220–300px 的侧轴，与主阅读轴轻微错位。
- 约 900px 以下：进入主阅读流，最大宽度使用 narrow measure。
- 手机：位于标题和摘要之后，左线 2px、左内距 14–15px；不得保留强行双栏。

## 交互与可访问性

批注本身静态、不可点击，不使用 Hover 或动画。蓝线不能成为唯一语义来源，文字必须独立说明判断。

## 禁止

圆角卡片、蓝色大底、Tooltip、系统通知、金句海报、英文 `Editor's Note` 装饰标签，以及为每篇列表内容都附批注。

## 验收

移除蓝线后，文字仍像有依据的编辑判断；移除整条批注后，主标题层级仍完整。若批注比摘要更先被注意，失败。
