# Pattern：Article Header / 文章详情页头部

## 目的与范围

用标题、摘要和最少元信息建立文章阅读入口。只覆盖内容类型、标题、摘要、必要元信息和可选编辑批注；不包含 Header、正文、目录、分享、作者卡、封面、推荐内容或 Footer。

## 信息顺序

`主标题 > 摘要 > 编辑批注 > 内容类型 > 元信息`

- 主标题是唯一绝对主角。
- 内容类型是可访问的文本链接；不显示为胶囊。
- 元信息只显示真实存在且对阅读有用的字段，允许完全省略。
- 编辑批注按 `editorial-note.md` 执行。

## 桌面结构

- 外层最大宽度 1180px，推荐边距 `calc(100% - 112px)`。
- 主阅读轴上限 780px；侧注轴 220–280px；间距 64–104px。
- 左对齐，不使用居中 Newsletter 头部，也不使用“左文右图”Hero。
- 标题 54–66px、行高约 1.14、字重 650 左右；最长 2–3 行。
- 摘要上限约 650px，约 21px / 1.72；与标题有明确停顿。
- 侧注从标题/摘要区域中段开始，不与标题首行同权。

## 移动结构

- 手机横向边距 20px，单列。
- 顺序：内容类型 → 标题 → 摘要 → 元信息（若有）→ 编辑批注。
- 标题 36–40px、行高约 1.2，目标 3–4 行；不得用手工 `<br>` 锁死所有标题。
- 摘要约 18px / 1.72；批注约 16px / 1.72。
- 第一屏无需强行容纳所有信息，优先让标题和摘要自然呼吸。

## 字体与换行

- 使用 `tokens.md` 的真实系统字体栈，不假设 Inter。
- 中文 `line-break: strict`，标题可用 `text-wrap: balance`，摘要可用 `text-wrap: pretty`；必须在目标浏览器验证回退行为。
- 主动断行只用于经编辑确认的特殊标题；数据驱动标题默认自然换行。

## 链接与状态

- 内容类型链接触控高度至少 44px。
- Hover 只改变文字色或下划线；不移动布局。
- `:focus-visible` 使用 3px `--mily-focus-ring`、5px offset。
- 无进入动画；如存在颜色过渡，使用 160ms 并在 reduced-motion 下移除。

## 允许与禁止

允许发丝顶线、非对称侧注和结构性留白。禁止完整容器卡、封面占位、英文微标签、Issue、标签堆、按钮组、分享工具、作者头像、发光或几何装饰。

## 验收

- 两秒内标题是唯一主角。
- 390 / 768 / 1440px 无横滚，阅读轴稳定。
- 无图仍成立；元信息缺失时不留空洞。
- 与首页 Hero 和编辑文章组共享暖白、蓝灰、规则线和批注语法，但不复制其布局。
